# Second Brain screen designs

Desktop reference frames for the Second Brain workspace. Sample company is Northwind Labs. Maya Chen is the administrator. Jordan Hale, Priya Shah, and Sam Ortiz are members.

Use these as layout and copy references. The shell is a dark left navigation on a warm stone canvas, with teal for primary actions and a gold CC mark for the assistant.
