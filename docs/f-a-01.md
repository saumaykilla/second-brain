# f-a-01 — Message Classification

Lane: **Person 1 — Capture (sources to Atlas)** · Covers: R7, R10

## Goal

Label every incoming message so only the right ones reach extraction and the dead-end check.

## User-visible behavior

Each captured message is stored and labeled `decision`, `attempt_start`, `attempt_result`, `intent`, `question`, or `noise`.

## Scope / out of scope

In scope:

- Classifier using the harness small model and prompt.
- Label stored on the message.
- Unit tests over labeled Orbit samples.

Out of scope:

- Extraction.

## Acceptance criteria

- Noise is stored and goes no further.
- Classification uses the harness prompt, not a hard-coded one.

## Verification steps

1. Run the classifier unit tests.
2. Classify 20 labeled Orbit messages and record accuracy.

## Dependencies

- `f-sh-03` Harness Config v1
- `f-sh-04` Shared Types, Contracts, and Orbit Fixture
