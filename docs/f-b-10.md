# f-b-10 — Screens read project memory, not sample data

Lane: **Person 2 — Recall (Atlas to answers and UI)** · Covers: R1, R14

## Goal

Every screen shows the connected project's own memory from MongoDB. The Orbit sample fixture is used only when no database is configured (tests and offline development), never as product content.

## User-visible behavior

Timeline lists the project's recorded decisions and attempts from the database and says so plainly when there are none yet. Capture is a working form: a message is stored, labeled, and shown with the project's recent captures. Ask, Check, Graph, Lab, and Impact use the configured project and no longer carry Orbit example questions, sample plans, or sample descriptions. Every screen has an honest empty state.

## Scope / out of scope

In scope:

- Timeline and Capture read and write MongoDB for `DEFAULT_PROJECT_ID`.
- `POST /api/capture` stores a message through the `ingestMessage` contract.
- API routes default to `DEFAULT_PROJECT_ID` instead of the literal `orbit`; client pages stop sending a hardcoded project id.
- Retrieval, cited answers, and the check route stop reading the fixture when a database is configured.
- `getActiveHarness` returns the v1 harness configuration for any project when the database has no active version, so retrieval and reflection have settings without sample records.
- Orbit-specific copy and example buttons removed from screens.

Out of scope:

- The ingest pipeline itself (`f-a-03`); Capture uses the placeholder labeling until it lands.
- Changing `lib/types.ts` or contract signatures.

## Acceptance criteria

- With a database configured and an empty project, Timeline, Graph, Lab, and Impact show empty states and no Orbit record.
- Capturing a message stores it in `messages` and shows it on Capture with its label.
- No `app/` or `components/` file contains the literal project id `orbit` or Orbit example text.
- Offline (`MONGODB_URI` unset) the fixture still backs `tests/shared.test.ts`.

## Verification steps

1. `pnpm typecheck` and `pnpm test` offline.
2. `rg -n "orbit|Orbit" app components` returns nothing.
3. In the browser: Timeline shows the empty state for the configured project; Capture stores a message and lists it; Ask, Check, Graph, Lab, Impact load without sample content.
4. With the env exported, `/api/check` on the socket.io plan returns no match for the empty project.
