# f-a-06 — Slack Event Capture

Lane: **Person 1 — Capture (sources to Atlas)** · Covers: R7, R29

## Goal

Receive Slack messages safely and send them through the pipeline.

## User-visible behavior

A message posted in a connected Slack channel is stored and processed once.

## Scope / out of scope

In scope:

- `POST /api/slack/events` with signing-secret verification and URL verification.
- Deduplication on Slack event id.
- Calls `ingestMessage`. Intent messages are handed to the warning handler from `f-b-05`.

Out of scope:

- Posting replies (`f-b-05`).

## Acceptance criteria

- Invalid signatures get 401.
- Retries do not create a second message.

## Verification steps

1. Run the signature tests.
2. Replay the socket.io fixture event twice and confirm one stored message.
3. Send a bad signature and confirm 401.

- `f-a-03` Attempt Merging and the Ingest Pipeline
