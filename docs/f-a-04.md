# f-a-04 — Manual Web Capture

Lane: **Person 1 — Capture (sources to Atlas)** · Covers: R7, R25

## Goal

Let a member capture work from the web app when Slack is not live.

## User-visible behavior

On `/capture`, a member types or pastes a message, picks a thread or starts one, and sees what ProjectBrain extracted from it.

## Scope / out of scope

In scope:

- `/capture` page following `design/10-capture.png`.
- `POST /api/capture` calling `ingestMessage`.
- Result panel showing the label and the created or updated record.

Out of scope:

- Bulk import.

## Acceptance criteria

- A capture shows its label and record within one request.
- Validation errors are shown inline.

## Verification steps

1. Capture the WebSockets start and result in the browser and see one attempt.
2. Capture a noise message and see the noise label with no record.
3. Check loading and error states.

- `f-sh-05` App Shell and Design Tokens
