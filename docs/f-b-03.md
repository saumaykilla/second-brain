# f-b-03 — Ask the Brain

Lane: **Person 2 — Recall (Atlas to answers and UI)** · Covers: R16, R17

## Goal

Answer project questions with citations and never present a superseded decision as current.

## User-visible behavior

On `/ask`, a question returns a concise answer with cited attempt and decision cards.

## Scope / out of scope

In scope:

- `POST /api/ask` using Atlas Search plus vector search over attempts and decisions.
- `/ask` page following `design/03-ask.png`.

Out of scope:

- Chat history.

## Acceptance criteria

- AE3: auth answer cites Better Auth as current and JWT as superseded.
- The Postgres question cites the benchmark and Atlas Search.
- An unsupported question does not invent a dead end.

## Verification steps

1. Ask the Postgres question and open a citation.
2. Ask about auth and verify current and superseded.
3. Ask something unsupported.
4. Verify citations resolve in the same project.
